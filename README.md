## Logistics

- **Meetings:** Tuesday and Thursday run the same agenda. Each member attends one day a week. Leads run both days. Times can shift with availability — update the [when2meet](https://www.when2meet.com/?39001523-XiZcH) if those days do not work. Week 9 meets on Tuesday, Nov 24 only; Thursday, Nov 26 is a campus holiday, so anyone who usually comes Thursday comes Tuesday that week.
- **Fall setup:** the lab uses one shared [OpenRouter](https://openrouter.ai) account, so members can try both proprietary and open-weight models through one API. Each member gets their own key from a lead. Each key is labeled with the member's name and has a credit cap. Keys are for lab work only. ACM funds cover API costs; confirm with officers. The lab picks the replication paper by blind vote in Week 5. The vote is a form, open through both meetings, and the result is sent to the whole lab after both meetings.
- **Turning in work:** each deliverable is a row in the lab's Notion database. The row links a Google Doc (a one-page writeup, or the slides or paper in Weeks 8–10) and the repo with the code. Members work in their own repo for Weeks 4–6 and in a team repo from Week 7. See [Turning in work](fall/turn-in.md).
- **Weekly deliverables** keep everyone on the roadmap. Short feedback helps leads see what is working and where to help.

## Winter tracks

Group project proposal — pick one:

| Track | Deliverable | Focus |
| --- | --- | --- |
| Literature review | 5–6 page technical report | Critically review and synthesize state-of-the-art work on one topic |
| Kaggle (or similar) challenge | 3–4 page report, plus code and data | Implement and analyze a solution to a public competition |
| Dataset creation and analysis | 2–3 page report, plus the dataset and code | Collect, clean, and document a novel dataset, with baseline findings |
| Novel research problem | 3–4 page report, plus code and data | Define and attempt a new research question using techniques from the lab |

After the proposal, the quarter is a sequence of progress updates (some tied to a meeting) and ends with a **final presentation**.
